# Panduan Kontribusi (Contributing Guidelines)

Terima kasih atas minat Anda untuk berkontribusi pada pengembangan ekosistem open-source ini!

## 🚀 Alur Kerja Kontribusi
1. **Fork** repositori ini ke akun GitHub Anda.
2. Buat branch fitur baru: `git checkout -b feat/nama-fitur-baru`.
3. Terapkan perubahan kode dengan standar bersih, modular, dan teruji.
4. Lakukan commit dengan format konvensional (*Conventional Commits*):
   - `feat:` untuk penambahan fitur baru
   - `fix:` untuk perbaikan bug
   - `docs:` untuk pembaruan dokumentasi
5. Push ke branch Anda dan buat **Pull Request (PR)** ke branch `main`.
